# 청명고 6모 단어장 (6Mogoword)

청명고 6모 영어 단어 완벽 마스터를 위한 귀여운 단어장 앱입니다! 💖

## 🌟 주요 기능

- **단어장 목록**: 21번~39번 단어 챕터별 보기 및 전체 단어장
- **플래시카드 모드**: 카드를 뒤집으며 학습하는 기본 모드 (넘기기 기능 포함)
- **객관식 퀴즈 모드**: 4개의 보기 중 정답을 고르는 퀴즈 모드
- **스펠링 맞추기 모드**: 한글 뜻을 보고 직접 영어 스펠링을 입력하는 모드
- **반복 학습 지원**: 퀴즈나 플래시카드에서 틀리거나 넘긴 단어는 리스트 맨 끝으로 이동하여, 완벽하게 외울 때까지 반복!
